# Math Games

A small collection of single-file, browser-based math games with a bright,
child-friendly theme. No build step, no dependencies — open a `.html` file
directly, or open `index.html` to browse all of them.

Works on desktop and touchscreens/tablets (drag-and-drop uses Pointer Events).

## Play

Open `index.html` — it links out to every game below.

- **Factoring Trinomials** (`factoring-trinomials.html`) — Grade 11–12. Arrange
  algebra tiles into a rectangle to factor `x² + bx + c`.
- **Completing the Square** (`completing-the-square.html`) — Grade 11–12.
  Arrange algebra tiles into a perfect square.
- **Block Party — Prime or Composite?** (`prime-composite.html`) — younger
  kids. Build rectangles out of blocks to test whether a number is prime or
  composite.
- **Halving Towers** (`halving-towers.html`) — younger kids. Split a tower of
  blocks evenly into two, then write the number sentence.
